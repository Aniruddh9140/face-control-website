**EyeSync 2.0.1** is a reliability update for EyeSync 2, with a new option for more accurate voice typing.

### New: Accurate voice mode
A tick box under Voice typing in the EyeSync window uses a larger speech model: fewer mistakes, especially on Indian English accents, but each phrase takes 7 to 30 seconds. It downloads 190 MB once, from Hugging Face, and checks the file before using it. Your speech still stays on your PC. The normal fast mode stays the default.

### Fixes
- Voice typing no longer stops after a long phrase that takes a while to recognise.
- If what you said doesn't sound like English, EyeSync now tells you and types nothing.
- Calibration can now finish on a slow webcam (around 10 frames a second).
- The dashboard connection recovers by itself if the page falls behind, and a brief reconnect no longer undoes a pause.
- Only the real EyeSync website can wake the camera, matched by its full address.
- The background listener keeps running if EyeSync fails to start, and works while another program holds its ports.
- A camera problem while stopping no longer leaves EyeSync stuck.

### Install or update
Download **EyeSync.exe**, open it and click **Update** (or **Install**). Your settings and calibration are kept. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.

**Coming from EyeSync 1?** Uninstall the old EyeSync first (Windows Settings → Apps → Installed apps → EyeSync → Uninstall), then install this one and calibrate again.

**EyeSync 2.0.2** is a small stability update for EyeSync 2.

### Fixes
- If Windows blocks mouse input (for example on the lock screen or a security prompt), EyeSync now pauses the pointer and tells you, and the camera keeps running. Resume when your desktop is back.
- If the camera skips frames or gives bad eye readings during a blink, that blink is cancelled instead of causing a click.

Blink timing and your personal calibration are unchanged.

### Install or update
Download **EyeSync.exe**, open it and click **Update** (or **Install**). Your settings and calibration are kept. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.

**Coming from EyeSync 1?** Uninstall the old EyeSync first (Windows Settings → Apps → Installed apps → EyeSync → Uninstall), then install this one and calibrate again.

### Files
- **EyeSync.exe**: the whole program in one file.
- **EyeSync-2.0.2-source.zip**: the source, for developers (also in the `Brahmastra` folder of this repository).

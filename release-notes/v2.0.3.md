**EyeSync 2.0.3** fixes how calibration results are reported.

### Fixes
- If calibration fails, you now see the real reason instead of it looking cancelled.
- Cancelling just as calibration finishes can no longer overwrite a calibration that worked.
- The pointer turns back on by itself only after a successful calibration.

### Install or update
Download **EyeSync.exe**, open it and click **Update** (or **Install**). Your settings and calibration are kept. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.

**Coming from EyeSync 1?** Uninstall the old EyeSync first (Windows Settings → Apps → Installed apps → EyeSync → Uninstall), then install this one and calibrate again.

### Files
- **EyeSync.exe**: the whole program in one file.
- **EyeSync-2.0.3-source.zip**: the source, for developers (also in the `Brahmastra` folder of this repository).
